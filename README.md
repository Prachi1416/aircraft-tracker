# Aircraft Tracker

A full-stack Aircraft Tracker application built using FastAPI and React.js.

## Tech Stack

### Backend
- Python
- FastAPI
- Uvicorn

### Frontend
- React.js
- Vite
- JavaScript

---

# Project Setup

## Clone Repository

```bash
git clone https://github.com/Prachi1416/aircraft-tracker.git
```

---

# Backend Setup

```bash
cd backend
python -m venv venv
```

### Activate Virtual Environment

#### Windows

```bash
.\venv\Scripts\activate
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run Backend

```bash
uvicorn main:app --reload
```

Backend runs on:

```bash
http://127.0.0.1:8000
```

---

# Frontend Setup

```bash
cd frontend
npm install
```

### Run Frontend

```bash
npm run dev
```

Frontend runs on:

```bash
http://localhost:5173
```
